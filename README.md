# LaborCreator

Browserbasierter Editor für Laborskizzen (Versuchsaufbauten) – eine einzige, selbstständige HTML-Datei ohne Abhängigkeiten.

## Funktionen
- Geräte-Bibliothek nach Kategorien (Glasgeräte, Schliffgeräte, Elektro, Zubehör …)
- Drag & Drop, Auswählen, Verschieben, Drehen, Skalieren, Gruppieren
- Schläuche, Kabel und Krokodilklemmen mit Andock-Punkten
- Flüssigkeiten, Feststoffe, Flammen, Wunderkerze u. v. m.
- Undo/Redo, Zoom/Pan, Eigenschaften-Panel, Autosave
- Export als JSON, PNG, JPEG, SVG

## Benutzung
`index.html` im Browser öffnen (oder per GitHub Pages hosten).
